# AttributeSet 属性集

## 1. 结构（Structure）

**组成：**
```cpp
UCLASS()
class UAuraAttributeSet : public UAttributeSet
{
    UPROPERTY(BlueprintReadOnly, ReplicatedUsing = OnRep_Health)
    FGameplayAttributeData Health;
    
    UPROPERTY(BlueprintReadOnly, ReplicatedUsing = OnRep_MaxHealth)
    FGameplayAttributeData MaxHealth;
    
    // ... Mana, MaxMana
};
```

**数据结构：**
- `FGameplayAttributeData` - 包含 BaseValue（基础值）和 CurrentValue（当前值）
- `ATTRIBUTE_ACCESSORS` 宏 - 生成 Getter/Setter/Initter

## 2. 生命周期 / 完整流程（Lifecycle & Flow）

**创建时机：**
```cpp
// ASC 创建时，自动创建 AttributeSet
void UAbilitySystemComponent::InitializeComponent()
{
    if (AttributeSetClass)
    {
        AttributeSet = NewObject<UAttributeSet>(this, AttributeSetClass);
    }
}
```

**值修改流程（关键）：**
```
外部请求修改
      │
      ▼
PreAttributeChange()    ← 可以修改请求值（如Clamp）
      │
      ▼
SetHealth()             ← 修改 FGameplayAttributeData
      │
      ▼
OnRep_Health()          ← 客户端收到复制通知
      │
      ▼
PostAttributeChange()   ← 属性修改后回调（如血变0触发死亡）
      │
      ▼
广播给 UI              ← 通过 ASC 的委托
```

**复制流程：**
```cpp
// Server 修改
SetHealth(50.0f);  // 标记为脏，下次复制时发送

// 客户端回调
void UAuraAttributeSet::OnRep_Health(const FGameplayAttributeData& OldHealth)
{
    GAMEPLAYATTRIBUTE_REPNOTIFY(UAuraAttributeSet, Health, OldHealth);
    // 触发本地回调
}
```

## 3. 职责边界（Responsibility）

| ✅ 应该做 | ❌ 不应该做 |
|----------|------------|
| 定义属性的数据结构 | 处理游戏逻辑（如"血量为0时死亡"） |
| 实现属性复制和回调 | 直接修改其他系统的状态 |
| 在 PreAttributeChange 中 Clamp 值 | 触发视觉效果（Cue 职责） |
| 提供属性访问器（Get/Set/Init） | 处理输入响应（ASC 职责） |

**边界原则：**
- AttributeSet 是**数据容器**，不是**逻辑处理器**
- 游戏逻辑应该在 `PostAttributeChange` 或外部监听回调中处理

## 4. 关键原理（Principle）

**BaseValue vs CurrentValue**
```cpp
FGameplayAttributeData
├── BaseValue      // 基础值（装备、等级决定）
└── CurrentValue   // 当前值（Buff/Debuff 修改）
```
- **GE 修改的是 CurrentValue** - 临时效果
- **升级/换装修改 BaseValue** - 持久变化

**网络同步优化**
- `ReplicatedUsing` - 只在值变化时复制
- `DOREPLIFETIME_CONDITION_NOTIFY` - 控制复制条件和通知方式
- 预测（Prediction）- 客户端先修改，服务器验证后校正

**宏生成代码**
```cpp
ATTRIBUTE_ACCESSORS(UAuraAttributeSet, Health)
// 展开后生成：
// GetHealth() - 返回 CurrentValue
// SetHealth(float) - 设置 CurrentValue
// InitHealth(float) - 初始化 BaseValue 和 CurrentValue
```

## 5. 使用模式（Industry Pattern）

**属性分类策略：**
```cpp
// Primary Attributes（基础属性）
Strength, Intelligence, Agility  // 决定 Secondary

// Secondary Attributes（次级属性）
MaxHealth, MaxMana, AttackPower   // 由 Primary 计算

// Vital Attributes（生命属性）
Health, Mana                      // 实际战斗中使用
```

**GE 修改模式：**
```cpp
// Instant GE - 立即修改（如治疗药水）
Effect.DurationType = Instant;
Effect.Modifiers.Add({Health, +25, Add});

// Duration GE - 持续一段时间（如 Buff）
Effect.DurationType = HasDuration;
Effect.Duration = 10.0f;

// Infinite GE - 永久（如装备加成）
Effect.DurationType = Infinite;
```

**常见坑：**
- **忘记 ReplicatedUsing**：属性不同步，客户端看不到变化
- **直接 SetHealth 绕过 GE**：破坏 GAS 流程，无法追踪来源
- **在 AttributeSet 里写业务逻辑**：导致代码分散，难以维护
- **Base/Current 混淆**：升级时应该修改 BaseValue，不是 CurrentValue
