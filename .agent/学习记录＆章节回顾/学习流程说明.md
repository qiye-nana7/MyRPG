# 互动式学习流程

## 模式

1. **你看完视频章节**
2. **我出题**（设计原理、代码分析、扩展场景）
3. **你回答**（可以写代码、画流程图、或文字描述）
4. **我判断对错** + 给出关键点的解释

## 问题类型示例

### 类型A：概念理解
> "为什么 EffectActor 选择用 GameplayEffect 修改属性，而不是直接调用 SetHealth()?"

### 类型B：代码分析
> "这四行代码中，如果去掉 AddSourceObject(this) 会有什么影响？"

### 类型C：设计决策
> "为什么 ASC 放在 PlayerState 而不是 Character？什么情况下应该放在 Character？"

### 类型D：扩展场景
> "现在要在血瓶上加一个冷却时间，你会怎么设计？"

## 记录格式

每个章节一个文件，结构：
```
## 章节：Chapter X part Y "标题"

### 问题1：...
**你的回答：**
（用户填写）

**判断：**
（正确/部分正确/需要补充）

**关键点：**
（解释核心知识点）
```
